Projeto CalculaThon.

Calculadora em Python para realizar as 4 operações básicas matemáticas e mostrar o funcionamento e codificação de forma amigável e descritiva para novos programadores.

Criado usando Google IA Studio na aula 1 - Imersão Engenharia de Software Dev na Era da IA
